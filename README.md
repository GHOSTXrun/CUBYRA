# CUBYRA

Static website for CUBYRA.

## Preview

Open `index.html` in a browser. No build step or package installation is required.

## Files

- `index.html`: page content, styles, existing chart interactions, and orange code rain background.
- `cubyra-logo.png`: CUBYRA logo.

The code rain respects the system reduced-motion preference. Google Fonts requires an internet connection; system fonts are used as a fallback.

## GitHub Pages

In repository **Settings > Pages**, select **Deploy from a branch**, then choose **main** and **/ (root)**.
